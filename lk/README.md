# ЛК клиента «Маркет вакансий» — Ventra GO! (HTML-прототип)

Статичный кликабельный прототип личного кабинета клиента для размещения вакансий
и работы с откликами. Без сборки — откройте `index.html` в браузере.

## Экраны
| Файл | Раздел | Возможности |
|---|---|---|
| `index.html` | Дашборд | активные вакансии, новые отклики, истекающие публикации |
| `vacancies.html` | Вакансии | таблица + фильтры (бренд, должность, занятость, формат, статус, поиск), действия |
| `vacancy-new.html` | Создание | таб «Поштучно» (все поля + справочники) и «Импорт из Excel» (превью + валидация строк) |
| `templates.html` | Шаблоны | сохранение/применение/удаление шаблонов вакансий |
| `responses.html` | Отклики | режимы «Все» и «По вакансии», фильтры, экспорт в Excel (CSV) |
| `map.html` | Геопоиск | торговая точка на карте + радиус 1/2/3/5 км, кандидаты вокруг, экспорт |

## Соответствие материалам
- **Поля и справочники** — из `шаблон_загрузки_вакансий.xlsx` (бренды, должности,
  тип занятости, формат/график работы, опыт, пол, возраст) и продуктовых требований (PDF).
- **API** — из `openapi.yaml`: `POST /api/v4/permanent-vacancies` (создание, идемпотентность),
  `GET /api/permanent-vacancy/leads` (отклики), webhook-подписка на отклики.
- **Геопоиск** — кандидаты берутся из отдельной базы с координатами (`CANDIDATES` в
  `assets/data.js`), радиус считается по формуле Haversine. В откликах API координат нет —
  это согласованное допущение прототипа.

## Технологии
HTML + CSS + ванильный JS, карта — Leaflet (CDN). Авторизация не реализована (по ТЗ).
Данные — мок (`assets/data.js`).
